# Houseplant Light Sensor

This project is for designing a device to measure the light exposure for indoor houseplants. Metrics include current light intensity and a 2-day average.

## Parts:

- **Adafruit VEML7700 Ambient Light Sensor**  
- **ESP32 Development Board**  
- **Waveshare 2.9‑inch E‑Paper Display Module**  
- **SD Card Reader**  
- **PLA Filament**  
- **Batteries**
