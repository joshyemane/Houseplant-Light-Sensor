# Houseplant Light Sensor

This project is for designing a device to measure the light exposure for indoor houseplants. Metrics include current light intensity, the average light exposure in a day, and a 2-day average of light exposure.

## Parts:

- **Adafruit VEML7700 Ambient Light Sensor**  
- **ESP32 Development Board**  
- **Waveshare 2.9‑inch E‑Paper Display Module**  
- **SD Card Reader**  
- **PLA Filament**  
- **Batteries**
- **Printed Circuit Board**
- **Jumper Wires**
